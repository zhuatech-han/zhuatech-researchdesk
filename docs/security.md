- 文件在私有数据库，无公开静态地址；只允许附件下载并设置nosniff/no-store。解析PDF、JPEG、PNG并限制页数、像素、容量；不是杀毒或内容净化服务，不能保证排除所有恶意文件。原始历史和结题文件不可被覆盖，下载者应使用受维护的阅读器。
- 财务导入拒绝公式、外链、宏、多工作表及超限文件；ZIP解析限制解压比例与条目。CSV导出对公式起始字符加前缀，数据库原值保持原样。
- 凭证号／行号全实例唯一，项目编号、部门代码、用户名等稳定标识不改写；经办／复核不同人。仅完整冲正，防止重复反向核销；审计保留动作与原因。
