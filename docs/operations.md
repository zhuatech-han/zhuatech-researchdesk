# ResearchDesk 操作手册

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 商业授权或深度定制微信 zhuatech / zhuatech2。

## 第一次使用

管理员登录后维护部门和人员。初始管理员、角色及管理部门受保护；管理员在右上角修改本人密码。为科研负责人、科研管理复核、财务经办、财务复核分别建立账号；不要共用账号完成独立复核。创建或停用角色权限、账号和部门后，下一次请求即重新检查。

仅隐藏菜单不会取消接口权限；取消业务能力应修改角色权限。本人参与范围适用于负责人或启用成员；财务批次需要部门或全部范围。只读审阅角色为全部范围，机构应按实际需要新建更窄角色。

## 立项与预算

1. 科研负责人在“科研项目”新建草稿，填写本部门、本人或授权负责人、日期及项目编号。编号、部门和负责人创建后不允许改写，录错且空草稿可删除重建。
2. 在“文件与历史”上传真实合同／批复 PDF、PNG 或 JPEG，再建立资金来源，关联正确文件。每个来源有独立合同金额，来源总额不超过1000亿元。
3. 在“成果与任务”建立至少一个结题必需里程碑，日期必须在项目期间内。
4. 新建预算版本，按来源、科目分行。每个来源预算总和必须等于对应合同金额。送审后由另一位具有预算复核权限的人批准。
5. 提交立项，由另一位科研管理复核人员批准。激活后合同来源及任务定义冻结，日期通过变更申请审签。

执行中调整预算须创建新版；系统复制当前有效行。修改后重新送审批准，旧版保留；新版不得使任何来源科目低于已支出和待审占用。驳回或撤回版本不改变有效预算。

## 到账和财务核对

财务经办在项目“实际到账”登记线下核实凭据，另一财务复核账号核实后才增加可用资金。到账合计不得高于来源合同额。录错凭据驳回；已批准到账通过新记录完整冲正，不能使实际资金低于支出及占用。

先由管理员按部门维护九字段表头映射，再导入 UTF-8 CSV 或单工作表 XLSX。金额为元、最多两位小数；正数是支出，负数是完整冲正。系统只接入文件，不联网获取银行或财务系统记录。

“财务接入与对账”显示原始流水。选择归属项目，再填写来源、科目及金额分摊，合计精确等于凭证。分摊不能突破有效预算或该来源实际到账。待审立即占用额度，批准后转为支出，驳回释放占用。即使管理员经办也不能批准自己。

财务复核在“财务复核”查看原始凭证与每条分摊，核准或驳回并填写原因。无法归属科研业务的流水通过“排除”提交说明、由另一人批准；原始记录不删除。冲正填写原凭证号、行号和完整相反金额，系统沿用原分摊，不允许重分配来源或重复冲回。部分纠错先全冲，再导入正确的新凭证号／行号。

## 成果、日期和结题

里程碑上传同名文件会生成下一版本，原文件保留。提交验收时冻结每个名称的最新且未撤回版本；每轮1至10个不同名称。独立人员验收通过或退回补充，已通过成果须先“重新编制”才能上传。撤回保留旧字节，不使更旧版本自动成为当前版。

项目或里程碑改期填写新日期与原因，另一科研管理复核人员批准；项目延期先于超出原结束日的任务改期。不得将项目结束日改到已有任务或已核对凭证之前。

结题页逐项列出未验收成果、未决预算、资金、财务核对和日期变更。处理完毕后申请结题；有结余须说明安排。提交后冻结项目写入；另一人批准后下载 ZIP，内含快照、摘要、财务CSV和当时冻结文件。项目再次打开也不会覆盖旧结题材料。结题不会自动划转或退还资金。

## 提示和数据保护

到期／逾期任务只在站内总览显示，按全局截止日期列出最早100条可见未验收任务，天数在系统参数配置。不发送邮件、短信或微信提醒。账号看不到某项目时，其文件、报表和导出同样不可访问。不要把业务材料放入公开仓库；导出和备份须按机构要求保管。文件容量、单文件3MB、项目100版本限制均会累计历史版本。
